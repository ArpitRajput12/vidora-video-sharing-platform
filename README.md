# Vidora — Full-Stack Video Sharing Platform

Full-stack video sharing and creator platform built with React, Node.js, Express and MongoDB.

## Product

Vidora

## Features

- User authentication
- Video upload
- Video sharing
- Video discovery
- Likes and dislikes
- Comments and replies
- Subscriptions
- Playlists
- Community posts
- Creator dashboard
- Analytics
- Responsive dark-mode UI

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- React Router
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Cloudinary
